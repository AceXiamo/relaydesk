# 项目助手

任务讨论使用当前项目名、项目级 Agent 指令、任务内容、要求、状态、负责人和最近 12 条讨论作为上下文。点击「询问助手」时，回答会写入该任务的讨论串。只有维护者主动修改任务要求或执行认领等操作时，队列状态才会变化。

默认使用本地规则，可以整理摘要、查询归属和梳理验收条件。开放式讨论可以使用兼容 OpenAI Chat Completions 的本地或远程模型。启动 Relaydesk 服务前设置环境变量，例如连接本机模型：

```sh
export RELAYDESK_AI_BASE_URL=http://127.0.0.1:11434/v1
export RELAYDESK_AI_MODEL=qwen3:8b
```

模型名应与模型服务里已安装的模型一致。访问需要认证的模型时，在运行环境中设置 `RELAYDESK_AI_KEY`。远程服务使用 HTTPS；回环地址也支持 HTTP。服务端向指定地址的 `/chat/completions` 路由发送请求。请求超时或模型出错时会退回本地规则。

反馈组件默认按用户描述选择追问。要允许用户在组件中使用已配置的模型追问，显式设置 `RELAYDESK_AI_INTAKE=1`。这条路径只向模型发送用户当前提交的反馈内容。使用远程模型时，任务讨论或已启用的入口追问内容会发送给该服务提供商。
